# When Should AI Follow? Task Structure and Joint Adaptation by Human and AI Agents

Replication package for the simulation results reported in the paper.

## Overview

The paper develops a computational model of joint sequential adaptation in which a human agent and an AI agent differ only in their memory regime: recency-weighted for the human, uniform memory for the AI, plus a memoryless stochastic variant for the AI. The model varies task scope (N), within-task coupling (K) and cross-agent coupling (C) across a modular structure and two sequenced structures (AI-to-Human and Human-to-AI).

This package reproduces every simulation result in the paper. One command runs everything:

```bash
pip install -r requirements.txt
python run_all.py
```

This takes about 30 seconds. It writes the simulation output to `output/results/`, the figures to `output/figures/` and the console logs to `output/logs/`, and ends by checking the output against the reference run shipped with the package (`Output matches the reference run.`).

## Data Availability and Provenance

The simulation results use no external data. All data are generated by `code/nkc_models.py` from a fixed random seed, so the package contains everything needed to reproduce them. The test problems are the full parameter grids listed under Model Conventions; every combination in them is simulated.

The code and data for the M&A experiment (Section 7 and the Online Appendix) are not part of this package.

## Variable Dictionaries

Each simulation run is one row. Parameter columns are shared by all three files.

| Variable | Description |
|---|---|
| `Simulation` / `Iteration` | Replication number (named `Iteration` in the Human-to-AI file) |
| `N_AI`, `N_Human` | Task scope: length of the AI's and the human's decision sequence |
| `K_AI`, `K_Human` | Within-task coupling: window length of each agent's adaptation rule (`K_Human` is 0 in the AI-to-Human file; `K_AI` is 0 in the Human-to-AI file, see Model Conventions) |
| `C` | Cross-agent coupling: number of upstream decisions inherited by the downstream agent (0 in the modular file) |
| `UA_AI`, `UA_Human` | Full decision sequence of each agent, as a list of 0s and 1s (left out with `--no-sequences`) |
| `PO_AI`, `PO_Human` | Payoff of each agent's sequence |
| `LP_AI`, `LP_Human` (`NLP_AI`, `NLP_Human` in the Human-to-AI file) | Number of local peaks in each agent's sequence |
| `APO_Modular`, `APO_Sequential_ATH`, `APO` | Joint payoff: the average of `PO_AI` and `PO_Human` |
| `AI_Updation_Type` | Human-to-AI file only: `rule-based` (uniform memory throughout) or `hallucination` (memoryless stochastic adaptation after position `N_Human`) |

| File | Task structure | Rows per replication |
|---|---|---|
| `modular_simulation_results.csv` | Modular (C = 0): agents work independently | 70,125 |
| `sequential_simulation_results_ath.csv` | AI-to-Human: the AI adapts first and seeds the human | 57,375 |
| `simulation_results_hta.csv` | Human-to-AI: the human adapts first and seeds the AI | 18,750 |

## Model Conventions

- **Uniform-memory adaptation (AI):** the next decision is 1 if the mean of the previous `K` decisions is at least 0.5, and 0 otherwise.
- **Recency-weighted adaptation (human):** the previous `K` decisions get weights 1 (oldest) to `K` (most recent); the next decision is 1 if the weighted mean is at least 0.5, and 0 otherwise.
- **Memoryless stochastic adaptation:** each decision is drawn uniformly at random. It is labelled `hallucination` in the output files for continuity with earlier versions of the code.
- **Initial history:** an agent without inherited history starts from `K` i.i.d. Bernoulli(0.5) decisions, which count toward its payoff. Sequences with `K = 0` are not updated and are all zeros.
- **Sequenced structures:** the downstream agent's sequence starts with the upstream agent's first `C` decisions (when `C <= K` of the upstream agent, these are its random initial decisions) and continues with a window of length `C`. The inherited decisions count toward the downstream payoff. In AI-to-Human the human's payoff uses `K = C`; in Human-to-AI `K_AI` is 0, so the AI's payoff is its share of 1s.
- **Human-to-AI update mode:** each parameter combination uses one mode in each replication, chosen with probability 1/2. In memoryless mode, every AI decision after position `N_Human` (beyond the human's task scope) is random.
- **Payoff (`PO`):** the mean, over positions, of the parity (sum mod 2) of `K + 1` consecutive circular decisions. For `K = 0` this is the share of 1s; for `K >= 1` an all-ones sequence scores 1 when `K` is even and 0 when `K` is odd.
- **Local peaks:** positions at least as large as both circular neighbours, which for a binary sequence is the number of 1s plus the number of 0s flanked by 0s.
- **Parameter grids:** `N_AI` from 1 to 50 and `N_Human` from 1 to 10, including combinations with `N_AI <= N_Human`. Modular: `0 <= K < N` for both agents. AI-to-Human: `0 <= K_AI < N_AI` and `1 <= C < N_Human`. Human-to-AI: `0 <= K_Human <= N_Human` and `1 <= C < N_Human`.

## Computational Requirements

- **Software:** Python 3.12 or later (required by numpy 2.5.3), with the versions in `requirements.txt`: numpy 2.5.3, pandas 3.0.5, matplotlib 3.11.2. Tested with Python 3.13.16 on Linux, in a fresh virtual environment installed from `requirements.txt` alone. No other packages are needed.
- **Random seed:** fixed at 0 by default (`--seed`). The same seed reproduces the output exactly.
- **Hardware:** any laptop. Tested on 2 CPU cores (Intel Xeon, 2.8 GHz) with about 8 GB of memory; the figure script uses under 300 MB because it averages the CSVs as it reads them.
- **Runtime:** about 13 seconds per replication of all three structures, 10 seconds for the figures, and under a second for the worked examples. With `--iterations 1000`, the simulation takes about 3.5 hours and writes about 8 GB of CSVs (sequence columns are left out automatically).

## Programs

| Step | Script | What it does | Output |
|---|---|---|---|
| | `run_all.py` | Master script: runs the steps below in order | `output/` |
| 1 | `code/nkc_models.py` | Simulates the three task structures | `output/results/*.csv` |
| 2 | `code/make_figures.py` | Builds the simulation figures and the numbers quoted with them | `output/figures/` |
| 3 | `code/worked_examples.py` | Prints the Figure 2 worked example, computed with the simulation's own adaptation rules | `output/logs/03_worked_examples.log` |
| 4 | `tests/verify_output.py` | Compares the CSVs with the reference run in `tests/reference_output.json` (run automatically with the default seed and one replication) | `output/logs/04_verify_output.log` |
| | `code/NKC_Models.ipynb` | The simulation code as a notebook, with run and figure cells | same as steps 1 and 2 |

`run_all.py` accepts `--iterations` and `--seed`. `code/nkc_models.py` also takes these options:

| Option | Default | Description |
|---|---|---|
| `--case` | `all` | `modular`, `ath`, `hta` or `all` |
| `--iterations` | `1` | Replications per task structure |
| `--seed` | `0` | Random seed |
| `--outdir` | `results` | Output folder; CSV files are overwritten on every run |
| `--no-sequences` | off | Leave out the `UA_AI` / `UA_Human` columns to keep files small |

Each figure is saved as vector PDF and 300-dpi PNG, and `summary.json` records the numbers quoted with the figures. Fig. 7 is a conceptual schematic. Fig. 10 (heptiles of `K_Human / C` in the AI-to-Human structure) is not built, because there the human's window equals `C` and `K_Human` is recorded as 0. Figs. 12 and 13 belong to the M&A experiment.

Figure conventions:

- The x axis is `N_AI / N_Human`. AI-to-Human and modular panels (Figs. 3, 4, 8 and the left panel of Fig. 6) show ratios up to 10; Human-to-AI panels (Fig. 5 and the right panel of Fig. 6) show the full range.
- In Figs. 3 and 4 the left panel shows the mean joint payoff at each distinct ratio, smoothed by a centred rolling mean over 15 neighbouring ratios; in Fig. 5 it shows means within integer ratio bins. Fitted curves (the right panels of Figs. 3, 4 and 5, and Figs. 6 and 8) are least-squares polynomials over all runs, of degree 2 for the modular and AI-to-Human structures and degree 3 for Human-to-AI. Polynomial fits can leave the [0, 1] range at the edges of the data.
- A Human-to-AI run has a high-performing human when `PO_Human` exceeds 0.42 (`--h-threshold`).
- Heat maps use heptiles over parameter combinations: rows by `N_AI / N_Human`, columns by rank of the column variable. Cells show the mean over all runs in them. Fig. 9 leaves out combinations with `K_AI = 0`, where `K_Human / K_AI` is undefined.

## Reproducibility Check

`run_all.py` verifies its own output. To check a run by hand:

```bash
python tests/verify_output.py
```

The reference in `tests/reference_output.json` records, for each CSV from a run with seed 0 and one replication, its MD5 checksum, row count and the sum of every numeric column. A match on row counts and column sums confirms the same numbers; a matching checksum confirms identical files. The reference logs from the authors' run are in `output/logs/`.
